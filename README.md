# CodeAlpha Basic Chatbot A simple rule-based chatbot built in Python as part of the CodeAlpha internship. ## Features - Responds to basic greetings and questions (hello, how are you, bye) - Uses if-elif logic to match predefined replies - Runs in a continuous loop until the user types 'bye' ## How to run ``` python chatbot.py ``` ## Concepts used if-elif, functions, loops, input/output
